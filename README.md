# Portafolio – Andy Ochoa

Portafolio personal de **Andy Ochoa**, Desarrollador Full Stack Junior.

Hecho con **React 18, TypeScript y Vite**. Diseño responsive, en una sola página.

## Ejecutar en local

```bash
npm install
npm run dev
```

Abre http://localhost:5173

## Editar el contenido

Todo el texto (perfil, proyectos, tecnologías y trayectoria) está en `src/data.ts`.
Las capturas de los proyectos van en `public/proyectos/`.

## Build de producción

```bash
npm run build
```
